# Публикация «Сумма прописью» 3.0

Публиковать эту рабочую версию можно только после отдельного прямого подтверждения владельца.

Загрузите все файлы из архива в корень репозитория GitHub Pages. Файл `CNAME` уже содержит `summa.martsynkovskyi.ru`.

Ключевые файлы:

- `index.html`
- `assets/styles-v2.7.css`
- `assets/app-v2.7.js`
- `assets/pwa-v2.7.css`
- `assets/pwa-v2.7.js`
- `assets/brand/*.png`
- `assets/generated-icons/*.png`
- `assets/reason-icons/*.png`
- `manifest.webmanifest`
- `service-worker.js`
- папки `fonts` и `icons`

После публикации GitHub Pages может обновляться несколько минут.

# Сумма прописью v2.6

Статический сервис для расчета НДС и подготовки готовых формулировок суммы прописью для договоров, актов, счетов и других документов.

Домен: `summa.martsynkovskyi.ru`

## Возможности

- расчет НДС по ставкам 22% и 5%;
- режимы «НДС включен», «НДС сверху» и «Без НДС»;
- четыре формата записи суммы прописью;
- готовые формулировки «в том числе НДС» и «кроме того НДС»;
- варианты обоснования для операций без НДС;
- копирование отдельного результата или всего расчета;
- автоматическое склонение рублей и копеек;
- корректный ввод сумм с пробелами, точкой или запятой;
- локальное сохранение текущего черновика;
- история десяти последних расчетов с восстановлением, копированием и удалением;
- работа без интернета после первого открытия;
- адаптивный интерфейс для телефонов, планшетов и десктопов;
- локальный шрифт Golos Text без CDN и внешних запросов;
- автоматические тесты расчетов на странице `tests.html`.

## Горячая клавиша

`Ctrl + Enter` в Windows/Linux или `Cmd + Enter` в macOS копирует весь расчет одним блоком.

## Публикация на GitHub Pages

1. Загрузить содержимое проекта в корень репозитория.
2. В `Settings → Pages` выбрать публикацию из нужной ветки и корневой папки.
3. Убедиться, что файл `CNAME` содержит:

```text
summa.martsynkovskyi.ru
```

4. После публикации открыть сайт один раз онлайн. Service Worker сохранит основные файлы, после чего сервис сможет работать без интернета.

## Проверка расчетов

Открыть:

```text
https://summa.martsynkovskyi.ru/tests.html
```

Страница проверяет:

- разбор российских и смешанных числовых форматов;
- расчет НДС 22% и 5%;
- режимы «включен», «сверху» и «без НДС»;
- склонения рублей и копеек;
- четыре формата суммы прописью;
- граничное значение суммы.

## Безопасность и приватность

- backend отсутствует;
- внешние библиотеки, CDN, аналитика и трекеры не используются;
- расчеты выполняются в браузере;
- черновик и история сохраняются только в `localStorage` текущего браузера;
- пользовательские значения выводятся через `textContent`, без пользовательского `innerHTML`;
- применяется Content Security Policy без `unsafe-inline`;
- Service Worker кэширует только собственные статические файлы сайта.

## Шрифт

Интерфейс использует Golos Text по лицензии SIL Open Font License 1.1. Текст лицензии включен в `LICENSE-OFL.txt`.

## Версия

**2.6 от 13.09.2026**

Основные изменения версии 2.6:

- рабочая область уплотнена для 24-дюймовых Full HD-мониторов;
- сумма и ставка размещены рядом, режимы и служебные блоки занимают меньше высоты;
- выпадающие списки приведены к единому стилю и шрифту приложения;
- копирование всего расчета больше не включает формулировки для документов;
- формулировки копируются только отдельными кнопками, а их текст можно выделять вручную;
- заменены неясные пиктограммы параметров, итогов и очистки формы;
- сохранена адаптивная раскладка для мобильных экранов и мониторов высокого разрешения.


## База версии

- Полная сборка 2.6 создана точечным обновлением подтвержденной рабочей версии 2.5.
- CSS и JavaScript имеют уникальные имена, поэтому старый service worker не может смешать файлы разных версий.
- Все встроенные SVG получили явные размеры, `fill=none` и `stroke=currentColor`.
- При публикации замените содержимое репозитория целиком файлами из архива.


## Установка как приложение

На Chrome и Edge кнопка внизу страницы открывает системную установку. В Safari на macOS она показывает шаги «Файл → Добавить в Dock…», на iPhone и iPad - «Поделиться → На экран Домой». В Firefox для настольных систем кнопка скрыта, поскольку установка PWA через manifest не поддерживается.
